TEAM SEED PHOTO LIBRARY
=======================

Photos of CLEANED seed put in this folder show on the species' Seed ID tab for everyone using the app.

How to add one:
  1. In the app, open the species > Seed ID > Add a seed photo (or use a photo you already have).
  2. Open the photo and tap 'Share / save'. The file is already named correctly and resized.
  3. On GitHub, open this seed-photos folder > Add file > Upload files, and upload it.

File names must match exactly (lower case, hyphens, .jpg). Up to three per species:
  banksia-grandis.jpg, banksia-grandis-2.jpg, banksia-grandis-3.jpg

Tip: photograph seed on a plain light background with a ruler (mm) in the shot.
